ALLMA SAFETY AI – POLICE COMMAND CENTER (MASTER PROMPT)

Build a world-class Police Command Center for Allma Safety AI.

This is NOT an admin dashboard.

This is an AI-powered police operating system that allows authorized police officers to receive reports, verify incidents, dispatch officers, communicate with citizens, investigate cases, manage evidence, and monitor crime across Uganda in real time.

The experience should feel like Apple Intelligence, Linear, Arc Browser, Notion, Google Maps, Tesla UI, and modern emergency dispatch software combined.

The interface must be premium, modern, minimal, responsive, lightning-fast, and built for both desktop and mobile.

FINAL EXPERIENCE

This should not feel like a traditional police management system.

It should feel like the future of law enforcement technology in Uganda.

Every officer should immediately know:

• What is happening

• Where it is happening

• How urgent it is

• Who should respond

• What evidence is available

• What AI recommends next

The dashboard should enable the complete workflow:

Citizen Report → AI Analysis → Verification → Officer Assignment → Dispatch → Investigation → Evidence Collection → Resolution → Citizen Notification → Case Archive

Every screen should be premium, intelligent, beautifully animated, and optimized for speed, making Allma Safety AI feel like a next-generation command center built for Uganda.
